## `$ cat engineering-principles.md`

```text
model proposes       policy decides
submitted != settled reconcile unknown state before retry
live != testnet       label proof honestly
recovery is a flow    not an afterthought
```

I use coding agents aggressively, but never as evidence. A product is complete only when the real path persists through restart, failure, verification and recovery.
